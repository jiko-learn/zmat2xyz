Mixed Format Molecule Input

Mixed Format Details:

You can use mix format by define some atoms with exact positions (Cartesian/XYZ), then use Z-Matrix to add more atoms that reference previously defined atoms.

Example - Formaldehyde:

  First define atoms in Cartesian coordinates:

  C 0.000 0.000 0.000

  O 1.200 0.000 0.000

  Then add hydrogens using Z-Matrix references:

  H 1 1.100 2 120.0

  H 1 1.100 2 120.0 3 180.0

Z-Matrix Format Rules:
  • 2nd atom: Element j R (bond distance)
  • 3rd atom: Element j R k A (bond + angle)
  • 4th+ atoms: Element j R k A l D (full specification)

Angles, Dihedrals in degrees and Reference indices (j,k,l) refer to atoms in previous lines.
